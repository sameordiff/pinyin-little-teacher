# 拼音小老师 🌱

### 把老师发来的拼音作业，变成会说话的练习。

拍下作业，识别拼音；点一点，听拼读；读完一个词，收获一朵小烟花。

拼音小老师是一款为孩子和家长设计的**拼音作业辅助工具**。它把老师发来的纸质作业或作业图片，转成可以点击、听读和反复练习的卡片，让家长少一些逐字示范的疲惫，让孩子多一点愿意继续读下去的兴趣。

> GitHub 源码仓库已公开，可直接查看代码和使用说明。托管网页版的访问权限独立，当前可能需要登录 ChatGPT 并获得访问授权；也可以下载源码，在自己的电脑上运行。

## 为什么做这个小工具

每天老师布置的拼音作业，对刚开始学习的孩子来说，需要一遍遍听、一点点练。

家长常常要指着作业，从声母教到韵母，再带着孩子读出整个音节。遇到不熟悉的声调或词语，还要反复确认。教久了容易累，孩子也容易觉得枯燥。

这个工具希望帮忙做好其中反复示范的部分：**让作业能点读，让拼读看得见，让每一次练习都有一点小惊喜。** 家长可以把更多精力放在陪伴、倾听和鼓励上。

## 它能帮助孩子怎样练习

### 📷 拍下作业，变成点读卡片

上传老师发来的作业图片，或拍下纸质作业，使用 DeepSeek 识别其中的拼音、汉字和词语。

- 有拼音：识别音节与声调，整理成练习。
- 有汉字：补充拼音，方便点读和识字。
- 只有拼音：可以配上相应的示例字词，帮助孩子把声音与文字联系起来。
- 内容模糊或读音有疑点：提示家长核对后再开始练习。

只有拼音时，对应的汉字可能有很多种。工具补充的字词是学习示例，不是对原作业答案的唯一判断。

### 🔊 听清声母、韵母怎样拼在一起

普通音节按声母、韵母等部分示范，再读出完整音节；三拼音节也有相应的分步展示。读到哪个部分，哪个部分就会**变色、放大**，帮助孩子跟上正在听的声音。

整体认读音节按完整音节示范。例如 `zhī`、`chī`，不拆成声母加上“衣”的读音。

词语支持逐字练习：每个字都有对应拼音，练完最后一个音节后，再听整个词语的中文读音。

### ⚡ 点到哪里，就在这里读

**快速点读是默认模式。** 点击列表里的卡片，就在当前页面完成拼读、中文朗读和奖励展示，不必反复打开和关闭弹窗。

需要仔细练习时，可以选择“展开练习”，查看逐字卡片和拆分提示。打开内页时保持安静，孩子主动点击后才播放；也可以选择“全部听一遍”，依次听完整套练习。

### 🎆 一朵小烟花，鼓励再读一个

完成拼读并听完中文后，字上会绽放一次小烟花，或出现对应的图案奖励。

常见字词会配上小贴纸，例如苹果、树与叶子、太阳等；没有匹配图案时，随机出现星星或彩色烟花。给孩子一点期待，让练习更有参与感。

奖励表示这次示范播放完成，不代表孩子已经掌握，也不代替对孩子实际朗读的判断。

### ✅ 把需要练习的内容留下来

- **蓝色**：已经听过示范。
- **绿色**：标记为已读，或家长检查后确认读对。
- **橙色**：不会或需要继续练习。

支持收藏需要多练的内容，也能一键清除颜色，重新开始。家长可以检查孩子的独立朗读，按勾选结果记录分数；还可以录下孩子的声音，在本机回放对照。

**目前没有自动语音评分。** 听过、跟读过和能独立读出，是不同的学习状态。

## 怎么使用

1. **准备作业**：拍摄纸质作业，或保存老师发来的清晰图片。
2. **设置自己的密钥**：首次点击“DeepSeek 拍照识字”，按提示填写自己的 API Key。
3. **识别并核对**：对照原图检查拼音、声调和对应汉字，修改后保存。
4. **孩子点读**：点击音节或词语，听示范、看高亮，再自己试着读。
5. **家长陪练**：标记已读和不会，收藏难点，之后换个顺序再练一次。

不方便拍照时，也可以手动输入。支持以下形式：

```text
shù zhī | 树枝
zhé zhǐ | 折纸
苹果
```

## DeepSeek API Key 与隐私

**DeepSeek Key 只保存在本机，网站不存储你的 Key。**

- 勾选“保存在当前浏览器”：下次打开可自动读取。
- 不勾选：只在当前页面使用，刷新或关闭后需要重新填写。
- 可以在“家长设置”中更换或删除密钥；换设备、换浏览器或清除网站数据后需要重填。
- 拍照识别时，密钥与照片会经过本站后端临时发送给 DeepSeek；应用不会将密钥写入数据库或日志，也不会回退使用站主的密钥。
- 浏览器本地保存不是加密保险箱，共用设备建议选择仅本次使用。

照片不由本应用持久保存，识别时会交给 DeepSeek 处理。家长确认的练习内容、收藏和学习记录保存在当前浏览器；孩子的录音仅在本机回放，不上传用于评分。

### 如何开通自己的 API

1. 打开 [DeepSeek 官方开放平台](https://platform.deepseek.com/)，注册或登录账号。
2. 按官方提示完成所需验证，并在充值或余额页面充值 API 余额。
3. 进入 [API keys](https://platform.deepseek.com/api_keys)，创建密钥，复制到本工具的设置中。

金额、支付方式和计费规则以官方平台为准。本项目不代售密钥，不收取充值款。操作入口也已放在网页设置里，可参考 [DeepSeek 官方 API 文档](https://api-docs.deepseek.com/zh-cn/)。

### 哪些功能使用 AI

| 功能 | 当前实现 |
| --- | --- |
| 拍照识别拼音、汉字、词语，补充示例配字 | DeepSeek，加上程序的拼音字典核对 |
| 示范发音 | 已收录的真人音频与设备中文语音 |
| 图案与烟花 | 本地图案匹配和动画，无需生成图片的 API |
| 鼓励文字 | 程序预设 |
| 朗读检查与分数 | 家长确认与勾选，程序计算，没有 AI 自动评分 |

普通点读、手动输入和奖励特效不需要 DeepSeek API Key。

## 本机运行

需要 **Node.js 22.13.0 或更高版本**。

```bash
git clone https://github.com/sameordiff/pinyin-little-teacher.git
cd pinyin-little-teacher
npm ci
node scripts/dev-standalone.mjs
```

仓库为公开项目，可直接克隆；也可以从 GitHub 的 Code 菜单下载 ZIP 后解压运行。

终端显示 `Ready for local server credentials on hidden stdin.` 后，输入下面这一行并按回车：

```json
{"key":""}
```

然后打开 **http://127.0.0.1:8769**。DeepSeek 密钥在网页中填写，无需把真实密钥写进源码或终端命令。停止本机服务时按 `Ctrl+C`。

框架开发可使用 `npm run dev`，构建使用 `npm run build`。服务端接口必须部署在支持的运行环境中；仅把静态文件放到 GitHub Pages，不能运行拍照识别接口。原托管项目的标识保留在 `.openai/hosting.json` 中，迁移到新站点时需使用自己的部署配置。

## 使用说明与来源

识别可能受照片清晰度、手写圈画、声调大小和多音字语境影响，请先由家长核对，再交给孩子练习。设备合成语音的质量也会因手机或电脑而异，工具适合作为课后辅助，发音教学请结合老师的示范。

- 拼音音节录音主要来自 [audio-cmn](https://github.com/hugolpz/audio-cmn)，包含 Chen Wang 等朗读者的录音，保留上游署名与 CC BY-SA 许可。
- 当前 `ch` 教学呼读音及 `chī`／“吃”的完整示范使用台湾教育部《国语注音符号手册》的参考录音，相关音档采用 CC BY 4.0。处理和来源记录见 [ch-reference.json](public/audio/ch-reference.json)。旧实验裁切片段已停用。
- 字典使用 [pinyin-pro](https://github.com/zh-lx/pinyin-pro)；本地拼音字体使用 Noto Sans。
- 更完整的音频、字体及依赖说明见 [credits.html](public/credits.html)。二次分发请保留相应署名和许可文件；不同资源的许可不应混为一谈。
