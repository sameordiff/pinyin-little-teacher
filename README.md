# 拼音小老师

手机拍照识别拼音、汉字和词语，家长确认后自动点读、逐字拼读、识字。

## 当前功能
- 默认由 DeepSeek `deepseek-flash` 直接识别照片；原图加局部放大辅助读小声调。
- 支持单字、两字词和较短词语；只有汉字的照片补上拼音，只有拼音时配常用示例字词。
- 明确区分图片原字与推测的示例字；不确定或音调不匹配的内容交给家长校对。
- 每行可写 `shù zhī | 树枝`；也可只输入 `树枝` 自动配拼音。相同拼音的不同字会保留为同音字列表。
- 标准拼读：普通音节拆分，整体认读音节整体读；点开即自动播放，无规则讲解。
- 音节优先真人录音，词语和未收录音节用设备中文语音。DeepSeek 用于识别，不生成声音。
- 绿色已读、橙色不会、蓝色重听按钮；标记、收藏和家长检查分数保存在本机。
- 录音仅本机回放，没有自动发音评分。

## 源码
- `public/`：页面、交互、样式、字体、真人录音。
- `server/deepseek.mjs`：服务端 DeepSeek 调用、输入限制、结果规范化与拼音核对。
- `app/api/recognize/route.ts`：API 路由。
- `.openai/hosting.json`：原网站身份及服务器部署配置；不包含密钥。

## 服务端配置
每位使用者在网页中填写自己的 DeepSeek API 密钥，可选择保存在当前浏览器或仅当前页面使用。普通服务端环境变量 `DEEPSEEK_MODEL=deepseek-flash`。拍照接口必须收到本次用户密钥，不再回退到站主服务端密钥。
用户密钥由用户自己输入网页，仅按用户选择保存在浏览器；识别时在 HTTPS 请求正文中临时经后端调用 DeepSeek，不写入数据库、应用日志、Git 或源码包。上传照片会发送给 DeepSeek；网站不保存照片和录音，服务端只做内存转发。

## 本机运行
1. `npm ci`
2. 推荐 `node scripts/dev-standalone.mjs`，终端提示后通过隐藏输入传入 `{"key":""}` 启动，再在网页填写自己的 DeepSeek 密钥。
3. 打开 `http://127.0.0.1:8769`。

框架开发：`npm run dev`；生产构建：`node /绝对插件路径/scripts/build-site.mjs`。正式部署使用原 Sites 项目，并让每位使用者在网页配置自己的密钥。

## 限制
视觉识别仍可能误读声调、圈画和多音字。家长需核对后再让孩子学习；模型的“无疑点”不代表绝对正确。
只有拼音时无法唯一推断汉字，配字只是学习示例。词语发音依赖设备安装普通话声音。

许可及音频、字体出处见 `public/credits.html`。

### 逐字点读
打开和切换卡片时保持安静；点击拼音、汉字或逐字卡片才播放当前音节。最后一个音节播放结束后读完整词语。声母为橙色、韵母为蓝色，随实际音频开始变色放大，整体认读音节完整读。播放完成显示短暂烟花，切换或中断时取消。烟花表示听完，不代表孩子已掌握。

### 字上奖励特效
每个字按字形和拼音固定分配一种视觉组合，包含彩色烟花、星星、花朵、泡泡、彩虹、流星、爱心和绿叶八类。特效直接挂在刚点读的字/拼音上，整词完成时逐字同时庆祝。奖励只表示示范播放完成；中断、切换和检查模式清除动画。尊重减少动态效果的系统设置。

### 完整连播、快速模式与图案奖励
全部听一遍会打开每张卡片，完整拼读各音节，最后读中文并展示字上特效和图案奖励；展示约2.2秒后自动切换下一张，内页可立即停止。快速模式在列表卡片上直接完整拼读，播放声母、韵母、音节后读中文并展示图案烟花，不打开内页；只有“展开练习”进入内页。听过的字分别标蓝色；清除颜色会清除听读和手工颜色标记，保留家长检查历史。常见字词使用本地语义图案，不认识的字词奖励星星，避免配错图；图案无需额外 API 请求。

### 词语图案烟花
字上特效的粒子使用当前词语小贴纸的对应图案，例如苹果烟花全部为苹果、树枝烟花为树与叶子。表情图案按字素分组以保留组合字符；暂无对应图案时继续使用奖励星星。快速入口与内页、连播共用拼读引擎，整体认读音节仍完整读。

### 列表内快速点读
快速点读与内页共用拼读引擎，通过传入列表卡片作为显示区域，将声母/韵母高亮、中文朗读和图案烟花全部放在当前卡片。播放期间只更新卡片状态，保持动画节点存在；点击另一张卡片、切换模式或清除颜色时取消旧播放。

### 烟花播放时机
整次拼读仅在最终中文朗读完成后播放一次图案烟花。声母、韵母、音节以及词语中前几个字均只做发音高亮；整词奖励使用一个中心爆发，不再逐字重复。

### ch 声母与随机未匹配奖励
ch 改用真人 chi2 原始录音的 0.275–0.482 秒辅音释放与自然送气段，截止于约 0.485 秒的周期性韵母起点之前，带短淡化、0.83dB增益和静音补齐；完整 chi1 文件保持不变。新的 ch-initial-clear.mp3 替代此前仅57ms有效辅音的 ch-initial.mp3，避免太短难以听见。该片段是基于 CC BY-SA 3.0 录音的裁切改编，不是新录制的教师审核音频，可运行 scripts/build-ch-initial.py 重建。没有对应词语图案时，完成朗读后随机选择星星或彩色烟花，贴纸与所选效果保持一致；匹配图案继续使用词语图案。

### 当前 ch 发音校对版
已停用全部实验裁切声母。ch 呼读音与 chī／吃改用台湾教育部《国语注音符号手册》ㄔ 的完整原版示范，进行 MP3 转码及响度统一，声母呼读播放略快略轻并保留音高。完整 chī 和汉字吃始终共用同一录音。其他 ch 音节补齐 audio-cmn 原版 67 项真人整音，所有 Git blob 校验值和文件名已核验，标签存在时也核验 SWAC_TEXT；ch-pronunciation.html 提供对照试听、许可和检查范围。当前作业含 ch 的12项，以及67个带调音节的示例字均已做字典核对；这不是教师听审或自动发音认证。刹车和出去新增真人整词录音，未收录整词继续用设备语音。历史裁切脚本仅供留档，不用于当前教学。

点击拍照入口时，没有密钥先打开设置。提供官方平台注册、充值和创建 API Key 的操作说明。支持本机保存、仅当前页面使用、更换及删除；不做保存即联网验证，不额外消耗 API 额度。密钥格式检查通过不代表余额充足或密钥有效，实际识别返回的错误会明确提示。后端只接受本次调用的用户密钥，旧的站主密钥不再用于拍照识别。
