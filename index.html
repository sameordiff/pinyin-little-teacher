没有密钥？按这 3 步开通

  1. 打开 DeepSeek 官方开放平台 ↗，注册或登录账号，按平台提示完成所需验证。
  2. 在开放平台的“充值”或“余额”页面充值 API 余额。金额和支付方式以官方页面为准，调用按实际用量计费。
  3. 进入 API keys ↗，创建密钥，复制后粘贴到上方，再点击保存。

API 余额用于接口调用，与聊天网页的使用分开。我们不代售密钥，也不收取充值款。
